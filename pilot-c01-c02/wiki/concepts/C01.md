# C01 观察事实与推测

## Core Thesis
可直接核查的描述和对原因、经历、意图的猜测不同。

## Problem Definition
先说题目明确呈现的信息，再区分未直接给出的解释。

## Terminology
事实：可直接核查的描述；推测：可能的解释，需额外证据。

## Mental Model
看到/题设 → 事实；由线索猜原因 → 推测；再想如何核实。

## Minimal Implementation
说出事实、标出猜测、描述如何核实；不要求揣测人物心理。

- Inherits from: 无。

## Hint Escalation Ladder (Step 3c)
先独立尝试；H1、H2、H3 均不揭示完整答案；另设平行示范。

## Misconceptions (Step 3d — Cognitive)
可能把推测当成观察；仅在有证据时记录，避免给孩子贴标签。

## Mastery Check (Step 3g)
在不同情境中区分事实与推测并说明核实办法；动态评估、证据聚合及合成确认按适配协议执行，不凭上游 80% 门槛宣称掌握。
