# C02 多属性比较

## Core Thesis
固定相同的属性维度比较，才能说清相同与不同。

## Problem Definition
从“看起来像”转向比较颜色、形状及数量等具体属性。

## Terminology
属性：物品可比较的特征；维度：同一类特征。

## Mental Model
先选维度 → 对两个对象分别观察 → 比较 → 描述异同。

## Minimal Implementation
比较两个属性并说明结果；本阶段不要求复杂分类。

## Common Errors (Behavioral)
交叉比较不同维度，或只说“差不多”。
