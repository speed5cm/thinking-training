# 教学法、初始诊断与 Sigma Tutor 儿童化规则

> 本文件是教学设计说明，不是直接可运行的软件系统。**[研究证据]** 引自官方研究/试验；**[课程建议]** 是结合9岁儿童学习情境的设计；**[未验证假设]** 是本12周试教需调整的规则。

## 一、研究依据与不能推断的效果

1. **[研究证据] 元认知与自我调节**：EEF 2025-11-13第二版教学指南及2025年Toolkit综述强调计划、监控、评价策略的明确教授、模型示范及结合学科任务；Toolkit涉及355项研究。参见 https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/metacognition 与 https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/metacognition-and-self-regulation 。不能把整体教育成效直接等同为本课程效果。
2. **[研究证据] 数学诊断与教学**：EEF 2017数学指导强调以形成性评估理解学生知识、误区与反馈；参见 https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/maths-ks-2-3 。
3. **[研究证据] 口头表达与互动**：EEF 2025年口语互动证据综述包含188项研究，主要集中阅读理解、读写结果；可支持课程内的结构化讨论，但不能断言泛化至IQ。参见 https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/oral-language-interventions 。
4. **[教法来源]** Project Zero的See–Think–Wonder、Claim–Support–Question为有研究背景的可视化思维常规，其独立学习效果不应夸大。https://pz.harvard.edu/thinking-routines 。原常规文本及下载资料适用CC BY-NC-ND；本文件独立编写提问和任务。
5. **[研究证据，含负面证据]** EEF第二次P4C试验共198校，没有发现其所测学业及社会沟通指标的显著收益。提供项目的SAPERE现使用Thoughtful品牌：https://www.thoughtful.org.uk/ 。https://educationendowmentfoundation.org.uk/projects-and-evaluation/projects/philosophy-for-children-effectiveness-trial 。仍可使用其讨论结构，但不能宣传为提高成绩的有效保证。
6. **[未验证假设]** 本12周周期、20分钟时长、0—3评分、H0—H3提示、1/3/7/14天复习和升级标准是本项目独立拟定的操作参数，尚未经过对照试验验证。

## 二、首次能力诊断（W01D1与W01D2内完成，不另加课时）

**目的**：寻找起始难度及语言/操作偏好，不诊断智商、注意力障碍、学习障碍或心理特征。首两天先做六个短任务，每天3个；总计每个训练日仍20分钟，任务可用口头或画图回答，结束后保留正常观察练习。

| 探测编号 | 核心能力 | 原创起点任务 | 重点观察（不只看对错） |
|---|---|---|---|
| D01 | 观察分析 | 桌上有红笔和蓝书；成人说“有人一定刚在写作业”，指出可见与猜测 | 能不能辨认无证据推断 |
| D02 | 逻辑推理 | 红、蓝两种球配大、小两种盒子，列出全部搭配 | 是否有序、不重不漏（4种） |
| D03 | 批判性思考 | “我问了2个人，他们都爱苹果，大家一定都爱苹果”有什么问题 | 能指出样本范围不足 |
| D04 | 创造性思维 | 一个空纸盒，想出3个用途并说明如何做到 | 想法是否实质不同、可行 |
| D05 | 语言表达 | “想让图书角更安静”给出观点和一个理由 | 能把观点、理由分开说 |
| D06 | 独立解决/元认知 | “有12张贴纸，想平均分给3人”，你先怎么做，怎么算、如何检查 | 是否自主计划和复核（每人4张） |

**实施安排**：W01D1先做D01、D03、D05；W01D2做D02、D04、D06。每项约2—3分钟、诊断部分约9分钟；余下时间用于第1周正常观察/比较。试探时可以按孩子兴趣换主题，但逻辑结构必须保持一致。

**记录**：一项至少保存孩子原话/画图摘要、答案、正确性、理由、帮助程度、投入感受及是否熟悉题型。单次表现标记为“起点线索”，不可直接给出固定能力标签。中断或疲劳时标“无法评估”，不能按0分处理。

## 三、单次20分钟 Tutor 运行规则

1. **检索（2分钟）**：从上次或间隔复习任务中选一道简短非原题的微任务。
2. **策略示范（3分钟）**：成人或AI在**不同的平行例题**中公开思考步骤（think-aloud），不能直接替孩子解当天测评原题。
3. **探索（10分钟）**：呈现1道主任务，复杂时只问1个问题；留出安静思考、操作、画图时间。
4. **理由（3分钟）**：请孩子说“为什么这么想”“还有什么情况”，开放题允许多种立场。
5. **复盘（2分钟）**：孩子说今天有效的方法和一个待试方法；记录表现，生成下次任务。

**模型对话限制**：一次最多一个主要认知问题和一个必要追问；不同于连续追问五个问题。不得把完整答案放进儿童可见的提示文本。中文优先、句子简短、少用术语；允许语音、实物和图示。不默认生成过量视觉内容。

## 四、三级提示（H0—H3）及触发

- **H0 独立**：完整题目后先等待思考；认可画图、掰手指、实物操作。若孩子正在尝试，即使答案错误也不打断。
- **H1 轻提示**：孩子主动请求帮助、说不知道、明显长时间不动且同意引导，或已经尝试但卡在启动步骤时，问“我们已经知道什么？”“你准备先做哪一步？”。不给关键数字或答案。
- **H2 结构提示**：H1后仍无法推进且孩子愿意继续时，明确关注一个条件或图示：“先固定十位再列个位”。不把整个解答交给孩子。
- **H3 平行例题示范**：仍受阻或产生明显挫败时，用更简单且**非原题**的类似例子示范一个完整策略；本题可降级或留待复习。原题完整答案只在家长/教师视图中揭示。
- **暂停/切换**：孩子表示疲劳、烦躁或不想继续，立即允许暂停；连续2次受挫改为更简单的可成功任务；若仍不愿意继续则结束当天，不用题量惩罚。
- **时间只做提示信号**：[未验证假设] 若孩子沉默约30—60秒可轻问是否需要帮助，不以秒表强制推进。

### “不知道”分支

1. 先回应：“可以不知道。你希望先找一个线索、看看相似的小例子，还是今天先休息？”
2. 选找线索：H1→孩子尝试→必要时H2；选例子：直接在更简单的**平行题**做H3；选休息：暂停。
3. 当孩子说“不想回答为什么”，可改用“画出你怎么想”或“指出哪一步”；不强迫公开表达。
4. 同一知识点如果多次需要H3，标记“需补先修/重设语言难度”，不是“孩子不努力”。

### 正确答案之后还应做什么？

- 首次正确：请孩子用自己的话说明一条关键理由；若没有理由，判为“答案对，理解待验证”，而非立即掌握。
- 理由正确：提供**不同外观、相同逻辑结构**的新题检验迁移。
- 孩子能在陌生情境自主选策略、能指出错误与边界，且无H2—H3提示，才记录较高独立掌握。
- 严格区分“听过示范之后能够复述”与“未经提示能解决新题”。

## 五、错误与示范时机

| 情形 | 教学响应 | 禁止行为 |
|---|---|---|
| 算错但思路正确 | 请回看某个计算步骤，允许自行核对 | 立即说出正确数值 |
| 违反限制条件 | 指向“必须/至少/最多”字眼，要求重新检验 | 代替孩子列完方案 |
| 把推测当事实 | 问“你看到的是什么，哪部分是猜的？” | 嘲笑或急于否定 |
| 逆推错误 | 让孩子构造一个B成立但A不成立的情况 | 只说“逻辑有问题” |
| 开放问题立场与成人不同 | 只评价理由和证据，不评价迎合程度 | 强迫改成立场一致 |
| 两轮提示无进展 | H3在平行题做示范，再回到简化任务 | 无限连续追问 |
| 明显情绪受挫/拒绝 | 降低挑战、选择暂停或成功任务 | 用成绩、排名或羞耻激励 |

## 六、理解、迁移与独立性评估

**0—3能力量表（每个知识点独立记录）**：
- 0：未完成目标动作，且适当帮助仍无进展；疲劳等无法评估情况应另标NA。
- 1：在较多提示下部分完成；理由不清。
- 2：核心方法正确，解释了关键理由；只需少量H1支持。
- 3：未见过的新情境中独立完成，说明理由并主动检验限制、证据或反例。

**H提示强度单独记录**：H0完全独立、H1启发、H2结构、H3平行示范。不能把得到H3后答对的结果记为独立掌握。

**三种测试题**：练习题（同知识同形式）、迁移题（同结构异场景）、延迟复习题（至少隔几天且避免记忆原答案）。一个掌握标签需要多次证据支持。

**[未验证假设] 升级门槛**：最近3次同类学习机会至少2次能力评分≥2，提示主要H0—H1，至少一道独立迁移题成功；否则保持难度或补先修。此门槛不同于Sigma原版“概念总分约80%”，不可声称二者统计等价。

## 七、间隔复习与混合练习

- [未验证假设] 新知识首次学习后1、3、7、14天安排回顾；每次用2—4分钟且题面变化，记录是否独立答出。
- 每周五做一轮混合题，允许加入前两周知识，防止只按题型记套路。
- 遇到困难先重学最短必需先修（如C06卡住先回C01条件与事实，而非将所有内容重教）。
- 实施根据学校负担与孩子意愿调整，避免额外堆叠作业；休息不能被判低分。

## 八、每日、每周、阶段反馈

### 每日反馈（发给家长，短）

```text
日期/节次：W05D03
今天任务：样本范围判断
知识点：C07
事实表现：孩子指出“问了3人不能代表全班”；主动提出“多问一些人”
正确性/解释：正确/核心解释清晰
独立度：H1
评分：2/3（初步观察）
主要错误：核实方案未明确调查总体
孩子自评：“我会先看调查了多少人”
下次：换一个班级投票场景做2分钟复习
```

### 每周家长汇报（固定结构）

1. **已观察到的变化**：以具体作品/原话说明，不写“思维能力提高30%”。
2. **六能力快照**：每项0—3或NA，附样本证据数和帮助级别；样本不足则说明无法判断。
3. **需要巩固的知识点**：只列1—2项，关联对应误区及先修。
4. **体验与负担**：孩子的兴趣、挫败、主动提问、暂停情况；不公开排名。
5. **下周计划**：升级/维持/补先修的具体决定和理由。

### 阶段反馈

每第3周末使用三道新题+口头反思，分维度保存原答、提示等级、评价维度和日期；W12与起点不同题型但相似认知要求的任务比较。**单人、短期、自编量表不能证明智商变化或因果学习效果。**

## 九、Sigma Tutor 与 Wiki Ingest 的具体关系

**已核实源码**：
- Sigma：https://github.com/sanyuan0704/sanyuan-skills/blob/main/skills/sigma/SKILL.md
- Wiki Ingest：https://github.com/sanyuan0704/sanyuan-skills/blob/main/skills/wiki-ingest/SKILL.md

原版Sigma包含诊断、1—2问/轮、约80%掌握门槛、复习状态等要求，并有**“NEVER give answers directly”**的不可变规则。[来源事实]

**本项目实施建议：**
- 不要直接声称Sigma已有儿童适龄、情绪保护或家长答案视图功能；应由Codex在经家长确认后建立**儿童版配置/分支或包装层**，并清楚标注与原版严格不直接给答案规则的差异。
- 若不修改Sigma原核心规则：Tutor只可提问和提供符合原版约束的最小提示；**平行例题的完整示范由家长或教师在Sigma之外进行**，孩子无法继续时交由家长/教师处理，不得由未改版的Sigma直接揭示当题解答。
- 若家长明确批准儿童版教学变更：保留原题答案默认隐藏，允许在适当失败次数后由教师端查看完整解析；儿童端可看到简化版**平行题讲解**。任何直接解答当题的能力都应作为显式产品决策而非默认行为。
- 保留“先诊断、后推进”思想，但使用本项目的**多证据掌握门槛**而非照搬原版80%的口径。
- Wiki Ingest“每知识实体一页”可应用于C01—C14，使用Obsidian风格 `[[concepts/slug]]`；`wiki/index.md`与`wiki/log.md`随维护更新。
- Codex责任仅限编排和校验知识库：编号唯一性、先修无循环、闭合题答案一致、提示不泄答案、来源与许可检查、变式歧义审校、过程记录模板。**本阶段不构建完整应用。**

## 十、知识库治理规范

### 最小题目字段
`id`、`concept_id`、`age_range`、`abilities`、`level`、`stem`、`answer_or_rubric`、`reasoning`、`hints[3]`、`common_errors`、`variant`、`variant_answer_or_rubric`、`source_kind`、`source_url_if_licensed`、`review_status`、`verification_status`。

### 引导者的强制门禁
1. **来源门禁**：只有原创或明确许可材料可收录题目正文；公开免费不等于可入库。
2. **答案门禁**：封闭题须数学/逻辑二次校验；开放题要有明确过程量表，不可虚构标准唯一答案。
3. **教学门禁**：孩子端不出现最终答案、完整推理和教师评语内的隐含剧透；按H1→H2→H3循序。
4. **升级门禁**：单次答对不升级；必须跨新场景且帮助程度低。
5. **反馈门禁**：不说“智商提升”“已经全面掌握”；长期数据不足则写“尚无充分证据”。
6. **儿童隐私门禁**：默认最小记录、家长可查看/删除；不储存真实姓名、家庭住址、学校、照片或语音原件，除非家长明确决定并理解风险。

### Wiki Ingest 推荐流程
1. 先登记资料URL、版权许可、访问日期到 `sources.md`。
2. 从合法材料中人工提取教学**思想**，重新用自己的语言定义每个概念；严禁把有复制/数据库限制的来源原文粘贴进Wiki或用于自动抓取。
3. 建立独立的 `wiki/concepts/<slug>.md`、先修关系、对应原创题ID。
4. 更新`wiki/index.md`与`wiki/log.md`，检查知识点引用均存在。
5. 由Codex离线检查闭合题答案、元数据与四阶段周数；再由成人试教审核歧义和年龄适配度。
6. Sigma Tutor阅读每节对应知识点和一题儿童可见题面；答案、推理和完整评分标准保留教师视图。

## 十一、待验证假设和试教观察点

- 20分钟是否适合此孩子，且口语/动手任务占比是否需要调整。
- 每周五天是否在校内作业之外形成过高负担。
- 3级提示是否足以区分“临时卡住”和“缺少先修”。
- 0—3评分能否在不同引导者之间保持一致；需要从实际口头材料建立评分示例集。
- 12周课程是否出现跨题型迁移；没有对照组时只可做个人成长描述，不做因果归因。
