# 真实 Codex 隔离对话记录（成人审阅）

本记录包含题目、平行示范和可能泄露的答案，**不要展示给孩子**。使用固定题卡的临时副本及标为 SIMULATED_TEST_ONLY 的虚构审核数据；没有家长批准、没有真实儿童。`儿童可见`为 Codex 的最终消息；内部工具输出与评价见 `dialogue-internal/` 原始 JSONL 和 events。

执行：`codex exec --json --skip-git-repo-check -s workspace-write -C /tmp/child-coach-dialogue-simulation ...`，后续逐轮 `codex exec resume --json --skip-git-repo-check <同一线程> ...`。各轮为真实模型调用，不是预制脚本；脚本所写评估是模型输入，不代表人工判定。
