# 集成状态（未验收）

正式证据模块已使用按概念限定的 C01 家长确认摘要；旧格式只在全量摘要仍匹配时有效，否则须家长重新确认。旧版题卡证据检查归档、版本登记及审核记录，校验通过也暂不用于掌握判断。正式题卡和审核未因本次工作改变。

`scripts/sigma_session_store.py` 提供合并 state、session 和 turns 的单文件快照；实验适配现要求 Agent 对所有会话读写使用该接口，规划输入也读取快照。发现旧文件即停止，旧会话尚未迁移。单元测试注入替换失败和并发提交；指令不能阻止绕过接口的直接文件编辑，真实 Agent 行为、进程崩溃和断电恢复仍未验收。快照不覆盖 coach、正式证据或路线的跨文件事务，实验不授予教学许可。

实验规划存储使用稳定任务标识并继承完成状态，兼容可定位的旧规划完成事件。它尚未迁移到正式入口，也未完成真实规划工作流验收。

发布读锁与证据锁只保护按协议协作的访问。当前没有能阻止直接文件编辑或撤销的强制发布维护机制；也没有完成多文件发布事务及故障恢复。旧 Tutor/Planner 和 Sigma 实验入口仍并存。不得将本状态解释为 Sigma 正式上线或启动儿童学习的批准。
