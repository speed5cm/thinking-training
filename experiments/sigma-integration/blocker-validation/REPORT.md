# Sigma 集成阻断项：隔离修复与验收

结论：**仍不建议切换到儿童使用入口。** 本次继续原 Sigma 实验，在 `/tmp/sigma-blockers` 完成实现和测试；此目录中的 `overlay/` 是可审阅的隔离实验代码，不是已集成到正式代码的补丁。未修改正式题卡、审核记录或个人档案。试验结束时与工作区对比：13 个题卡文件及 5 个审核文件的 SHA-256 均相同。合成学习者和合成家长确认仅用于测试，不包含真实儿童资料。

## 正式授权

实验版 `coach.py` 在 `start --mode C02` 的原入口内检查 C01 掌握候选、证据中所引用题卡的当前版本及发布、家长确认和证据摘要，并检查 C02 硬先修与当前发布；C02 的后续训练操作重新检查。诊断使用 `diagnosis` 入口，不转换为正式掌握证据。原样调用 coach 的 C02 启动路径因此不能绕过此检查。

coach、证据采集及规划操作按“发布共享锁 → 化名锁”的顺序运行；C02 检查和启动事件追加处于同一化名锁内。发布编辑者必须持有 `.publication.lock` 独占锁。并发测试模拟发布者持锁撤销审核，确认启动等待并在撤销后失败。**限制**：锁是协作式协议；目前没有统一的发布写入工具强制所有维护者持锁，直接编辑文件可绕开协议。不能据此声称发布变更的所有竞态已消除。模拟数据测试通过了直接 C02 阻断、合成多题证据和模拟确认下的启动、确认过期后的 show 阻断、C01 审核撤销和重复启动。旧审批、卡片改动和旧版本的现有 coach 回归也通过；独立的 C02 旧审批实测尚缺。

## 路线与复习

`overlay/scripts/sigma_plan_store.py` 实验性保存 AI 候选的顺序版本、规范化内容 SHA-256、Wiki/证据/学习者输入摘要及历史，在读取时比较当前输入标记 stale。更新在共享发布锁和化名锁内验证候选并以单文件原子替换；语义内容仍由 Agent 提供。实验复习队列从已采集正式证据生成，保存来源会话、时间、建议日期和状态；一天仅是实验参数，不是科学结论。完成复习要求提供较新的同概念正式证据。**限制**：该关联不能证明新会话实际是一次复习；动态练习不会自动完成队列。Sigma 会话的其他 Markdown/JSON 状态仍由 Agent 分文件写入，未做到与规划同锁、原子一致和崩溃恢复；因此路线输入读取与这些未受锁保护的状态写入仍存在竞态。

自动测试验证版本递增、复习到期及队列恢复、正式证据关联、过期摘要及真实 Wiki 文件变化触发 stale。真实 Agent 在 C01 正式作答后生成第 2 个路线版本，带一个基于该模拟正式证据的未来 C01 复习项。一个单独的合成到期场景将模拟记录时间人为回拨两天：真实 Agent 检查到到期 C01，提出动态复习而未把它当正式测评。

## 回归与边界

`audit/tests-main-final.log`：28 项通过；`audit/tests-coach-final.log`：22 项通过；`audit/roadmap-check-final.log`：14 概念、2 个试点可用快照。原 coach 回归 `test_real_published_reviews_allow_all_modes` 旧断言假定发布即允许 C02，现在与新先修要求冲突；实验中该测试对先修授权进行了 mock，以继续测试原有发布快照，实际先修由新增的合成测试单独覆盖。这是测试适配，不是原测试原封不动通过。

实验 Agent 写出的 `state.json` 等文件并未通过统一原子 API，部分文件权限为 0644；个人目录被忽略并不等于加密或访问控制。发布锁目前仅是协作协议。现有路线与会话历史迁移尚未实现或在真实历史记录上验证。当前工作区此前已存在未提交的独立 child-sigma-tutor、tutor_loop 和 Planner 改动，实验没有删除或切换它们；README 中已有旧实验入口，合并前也须核对。家长文案只是 `PARENT-DRAFT.md`，未启用。

## 上线前

1. 强制发布维护入口采用同一锁，统一状态与规划提交的锁、原子写入及恢复；审查文件权限、历史迁移与失败恢复。
2. 修复并重测 Wiki 变化时先读材料、分析差异、再发布路线；不能用刷新摘要代替语义审核。
3. 用合成授权夹具开展真实 Agent C02 正式训练、正确结论错误理由、未发布题对抗及已显示动态例子的语义审查，保留逐轮日志。
4. 明确复习完成如何由可信证据和家长观察记录；复习不自动等于掌握。完成所有门禁和历史兼容验收后，再将 Sigma 设为唯一入口，停用重复 AI 编排，保留 coach 和 evidence 的确定性能力。
