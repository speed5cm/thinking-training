## 发现的阻断

1. **复习闭环未完成**：没有动态任务可安排、执行、分析并更新下次间隔。队列目前由正式证据驱动，`complete-review` 要求新的正式证据，不提供动态完成、加倍/缩短或续排。不能把普通动态问答伪装为正式证据。此次未执行到期动态复习，也未验证下次复习时间。
2. **路线更新过于频繁**：初始路线 1，在五次回答后升到路线 6；其中第 05 轮仅选择“看看相似的小例子”，Agent 把即时支持选择写入 `planning_basis` 并发布路线 5。暂停/恢复本身未触发路线更新。需把即时动作与真正影响中长期路线的判断区分开，同时保留实质性学习变化。
3. **分析留存不充分**：问题与回答以追加事件保留，会话文本保留各轮摘要；但最终快照的 `state.response_analysis` 只保留最后一轮详细分析，前面详细分析依赖本次单独保留的中间快照或 Agent 日志。常规会话存储不保证每轮完整分析可恢复。
4. **旧会话迁移、发布维护入口及跨模块故障恢复仍未完成验收**：本次未对历史个人档案做迁移；未验证发布/撤销受控入口或各模块中断后一致性恢复。
5. **正式授权范围有限**：C02 无先修拒绝和一个未登记合成草稿拒绝已由真实 Agent 测试；符合完整 C01 证据和家长确认后的 C02 训练未测试。本次不能凭动态练习或合成资料赋予正式授权。
6. **Wiki 恢复案例有边界**：这次旧正文在同一 Agent 会话中可重新取得并匹配摘要，测试只有简单注释。旧内容不可得、复杂编辑、冲突或进程中断后是否安全停止仍未验收。

## 与原有架构的关系

Sigma 原有教学行为包括调查、诊断、动态追问、路线、迁移、掌握检查和复习。儿童适配应负责适龄、一次一问、疲劳暂停及正式授权边界；coach、证据、存储和路线校验负责确定性工作。旧 Tutor 和 Planner 的独立 AI 编排仍与 Sigma 并存，历史依赖和迁移尚未验证，因此本次没有停用旧入口，也未更改任何教学实现。
