# Sigma 现状与验收记录（2026-11-08）

> 本报告是授权前的历史记录；后续真实 Agent 成人模拟结果见 [补充验收报告](live/REPORT.md)。

结论：本轮真实 Agent 连续教学验收未执行，不允许切换儿童入口。本轮先检查已有能力和回归，没有更改教学实现、正式题卡、审核记录或个人档案。此前的真实 Agent 实验是历史证据，不代表本轮通过。模拟结果不证明真实儿童的教学效果。

## 职责与重复

- 上游 Sigma 已负责 Wiki survey、诊断、路线推理、动态追问和答案分析、误区与反例、迁移、交错、掌握检查及间隔复习。其 80% 晋级、学习风格画像、固定 HTML 更新等不能直接作为儿童正式授权。
- Child Adapter 应负责适龄、一次一问、疲劳暂停、隐私、动态练习与正式测评分离；正式晋级仍须证据、先修和家长确认。现有实验适配是说明，不是已启用的正式入口。
- `child-sigma-tutor` 和 `ai-roadmap-planner` 现仍分别提供 AI 教学和规划指令；README 仍指向前者。它们与 Sigma 编排有重叠；历史数据及迁移尚未验收，不能直接停用。
- `tutor_loop.py` 是确定性持久化和部分门禁，尽管它自身不生成问题，其状态和旧 Skill 的教学流程与 Sigma 会话并行。`coach.py`、`learning_evidence.py` 的正式授权及证据职责应保留。
- `sigma_session_store.py` 管理单文件快照及修订冲突；`sigma_plan_store.py` 管理路线版本和基于正式证据的复习队列；`validate_personal_roadmap.py` 校验输入摘要和结构，不验证教学语义。跨模块不是一个事务。

## 仍需解决与复现

1. **复习闭环未实现**：`sigma_plan_store.py` 的 `complete-review` 要求另一个已采集的正式证据会话；动态问答无法完成任务，且没有按表现调整下一次间隔。阅读该脚本的 `queue` 和 `operate` 即可核对；`python3 scripts/sigma_plan_store.py --help` 可查看现有命令。不能将动态回答转换成正式证据。
2. **Wiki 变化先读后规划未通过真实 Agent 重测**：旧实验 `blocker-validation/audit/turn5-wiki-change.jsonl` 显示顺序错误；现有适配要求比较旧快照，但路线历史只保存摘要和计划，未保证保存旧 Wiki 内容以供比较。应在隔离副本修改 Wiki 后检验真实 Agent 的读取、差异分析、再规划顺序。
3. **会话协议依赖 Agent 遵守**：快照仅强制历史 turns 追加，不校验题目 ID、重复回答、待答题数量及分析与回答的关联；失败和修订冲突的单元测试不等于真实 Agent 操作验收。复现：阅读 `sigma_session_store.py` 的 `validate` 和 `operate`。
4. **旧会话迁移未完成**：发现任何旧 `state.json`、`session.md` 或 `turns.jsonl` 即拒绝读取；目前没有保留原件、核对及回滚的迁移工具。现有测试只验证安全阻断。
5. **发布维护入口缺失**：读取侧的文件锁只保护协作式写入，没有受控发布/撤销工具能保证维护操作持相同锁；不可声称直接文件编辑和发布竞态已受控。
6. **跨模块恢复未验收**：快照、路线、coach、证据独立持久化，尚无完整的中断后核对流程，不能声称一次操作跨文件全部成功。
7. **planning_basis 真实行为未验收**：单元测试证明普通快照修改不使路线失效、basis 变化使其失效；仍需逐轮验证 Agent 在实质性理解变化时确实更新，并确认不会因普通对话频繁重排。旧 Tutor 状态和正式事件仍独立纳入规划输入。
8. **真实成人连续流程未验收**：需要新会话逐轮验证诊断、路线、浅理由追问、多种解释、连续困难、暂停恢复、路线调整和复习。应保存实际 Agent JSONL、每轮输入及状态差异；不以预写对话或模拟证据替代。
9. **正式授权的 Agent 对抗和迁移验收未完成**：确定性回归覆盖未审核题及 C02 门禁，但尚需真实 Agent 行为验证；当前 C01 已发布题卡数不足以满足跨题掌握候选，不可通过构造真实儿童证据绕过。

继续真实 Agent 验收前，需要明确批准将必要的项目内容发送给模型服务。批准后仍须在隔离副本使用虚构学习者，不读取或导出真实个人记录，并按上述阻断逐项验收。批准本身不等于验收通过。
