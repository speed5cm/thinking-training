# 证据边界与待核问题

## 可追溯性
[[S17]] 汇集 R01—R11 的出处、限制与链接；[[S18]] 将研究证据、教学建议和未验证假设区分。它们均为项目二手材料，不等于已查阅所有论文全文。每个 C 页列出原项目给出的 R 编号，这些是参考映射，不是对每项因果效果的证明。

## 冲突、重复及缺口
- P4C 早期积极信号与后续 198 校试验未见所测指标显著收益，研究规模和测量范围不同，需并列呈现；不可保证成绩提升。
- 试点 C01/C02 与正式概念是同一身份的补充快照，不新增概念；若快照措辞有差异，以正式目录为课程身份依据并待人工核对。
- 元认知、口语研究综合和本家庭课程、AI 指导之间存在情境与结果差距，不能推导本课程有效。12 周与具体运行参数为项目假设。
- 各 C 页引文多为资源索引级别，缺少逐条定义和迁移效果的原始研究对应；尤其不能从商业产品描述推断效果。需人工查阅原始来源、研究方法、样本及适龄性。
- 原创题卡是示例而非研究，学习记录和模拟测试未导入。尚无对外部链接当前有效性及授权的重新核查。
