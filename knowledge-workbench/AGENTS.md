# 独立知识工作区规则

本目录仅供研究整理，不是儿童教学入口。先读 `upstream/AGENTS.md` 的 Wiki Ingest、Query、Health、Lint、Graph 工作流，再遵循以下项目边界；冲突时以本文件和仓库根 `AGENTS.md` 为准。

- 所有写入限于本目录；禁止更改正式 `../wiki/`、课程、Sigma、授权或学习证据。不要导入儿童记录或个人信息。
- raw 是不可修改的来源快照；新增版本应保留旧版、登记原路径与 SHA-256、关联同一来源身份。先维护导入清单，明确类别与排除项。
- C01—C14 只对应已有概念，不新增课程概念、改变先修或自动接入教学。新增理论只作为参考知识。原始研究、项目概念、假设、题目各自标识；未人工审核，缺依据或冲突须明确列出。
- 使用本工作区相对路径；WikiLink 只用唯一文件名（例如 `[[C01]]`、`[[S08]]`），以兼容上游 lint 和 graph。保留原始来源与版权限制，不将题卡当研究。
- 优先以编码代理执行上游自然语言工作流。`tools/ingest.py` 会直接覆盖 LLM 返回的路径，且不提供可靠去重、事务或权限边界；不得直接对正式工作区运行，先在隔离副本操作、核对差异，再人工选择迁入。转换工具可能在来源旁写入文件；使用独立临时副本转换。
- Query 保存综合页时明确用户要求。对 graph、lint 的模型语义结果和所有新内容保留待核状态。运行检查后如实记录失败及缺失依赖；不要以运行成功宣称研究或教学质量通过。
