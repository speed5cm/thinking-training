## 建议阅读顺序
1. `references/sources.md`：官方教材和研究来源，明确版权与适配范围。
2. `references/pedagogy.md`：证据、首次诊断、Sigma儿童教学约束、提示与评估规则。
3. `wiki/index.md` → `wiki/concepts/*.md`：14个可观察知识点，先修与迁移关系。
4. `curriculum/12-week-plan.md`：12周×5天=60节，四次阶段评估。
5. `question-bank/original-examples.md`：28道原创样题，每题三级提示、答案/评价、推理、错因、变式。
6. `question-bank/answer-audit.md`：答案复核范围、脚本断言及开放题审校边界。

## 证据标签
- `[研究证据]`：来自外部研究综合/试验的事实，见来源链接。
- `[来源事实]`：教材官网结构、年龄和版权声明。
- `[课程建议]`：基于研究和任务需求设计的实施方式。
- `[未验证假设]`：尚未在本课程场景中实证验证的时间、阈值和效果。

## 面向实施者
- 默认使用中文口头互动；9岁孩子可画图/指认/手写，不强制长段打字。
- 家长管理题库答案和评分；孩子端默认不显示答案。
- 不依赖商业教材授权即可使用本包原创内容；不能因此重新分发来源教材本身。
- 保护儿童隐私：仅记录学习行为，不记录真实姓名、学校、定位或不必要的敏感资料；家长有权查看和清除记录。

## Sigma 教学与规划（仅隔离验证）

Sigma 是唯一 AI 教学与规划核心。从仓库根目录启动支持项目 `AGENTS.md` 的 Codex 会话，请求“开始 Sigma 隔离验证”（使用虚构学习者）；项目指令会引导读取 `skills/child-sigma-tutor/SKILL.md`，再读取上游 Skill 和优先级更高的适配协议。也可手动让 Agent 读取该入口文件。入口依赖 Python 3 和仓库内文件，不是独立可执行程序；Sigma 动态出教学题和评估题，Coach 的固定题卡训练入口已关闭，原题卡和历史记录保留。规划须先准备候选、展示完整内容及摘要并取得明确的合成模拟家长确认，再经 Sigma 规划存储发布。路线不授予教学或掌握资格。
