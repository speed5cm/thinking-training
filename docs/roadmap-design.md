# Roadmap 原型与后续设计

## 审计与边界

- 课程知识以根 `wiki/index.md` 和 `wiki/concepts/` 为唯一维护源：概念定义、目标、能力、关系与参考来源在此维护。索引提供范围，概念页内的 `roadmap-metadata` 提供机器可读关系；其余字段直接抽取原文。`references/sources.md` 是来源登记，引用有效性检查只验证登记存在，不证明来源可靠或授权。
- `pilot-c01-c02/wiki/` 是现有 coach 使用的冻结兼容教学快照，不是第二份课程知识源。保留其内容和运行路径以保护已审核试点；若根 Wiki 的 C01/C02 定义、目标或关系改变，须人工比对该快照、题卡和来源，按现有流程审查后才更新快照或发布新版本。出现冲突时暂停受影响概念的教学，不能由生成器自动同步或授权。当前生成器不自动检测两份文本的语义冲突；这一人工检查是必要限制。
- `question-bank/original-examples.md` 是含答案的草案题库，概念页列出的题号也只是引用，均不证明发布。试点仅 C01/C02 的指定训练题通过既有 coach 审核、版本、快照、散列和 Wiki gate；Sigma 是唯一 AI 教学与规划入口，Coach 负责题卡执行和实时门禁；当前仅供隔离合成数据验证，儿童正式入口尚未开放。Roadmap 的状态为生成时快照，不构成运行许可；每次教学仍须调用 coach 重新验证。不存在任何自动审批。
- 12周60节为参考规划；原先修关系是课程设计假设，非经儿童学习实证验证的门槛。本原型保留原索引全部关系：除 C11/C14 外暂作完整概念的硬性先修；按索引明确说明，C11 的 C02/C09、C14 的 C01/C09 作为可穿插关系，允许早期局部练习，并不表示完整任务无需相关能力。关系应由课程负责人进一步审校。
- 六领域按 `references/pedagogy.md` 的 D01—D06：观察分析、逻辑推理、批判性思考、创造性思维、语言表达、独立解决/元认知。概念映射表明覆盖，不代表教学时长或质量均衡。

## 使用及验收

运行 `python3 scripts/generate_roadmap.py` 生成 `roadmap/roadmap.json` 和 `roadmap/roadmap.html`；运行 `python3 scripts/generate_roadmap.py --check` 校验文件未过期。验证失败时不写输出，已存在的旧文件仍可能存在，不可当成当前状态使用。索引、文件集合、ID、原先修与结构化关系一致性、六能力、来源编号和硬依赖有向图均被校验；图从所有无硬先修概念出发，未到达的节点视为循环或不可达。可穿插关系不参与阻断和拓扑排序。索引 ID 固定为 C01—C14；要增减课程范围须显式修改校验与审校。

验收命令：`python3 -m unittest discover -s tests -v`、`python3 -m unittest discover -s pilot-c01-c02/tests -v` 和上述 `--check`。原型测试包含缺页、缺失引用、无效来源、循环、题卡篡改、审核缺失、HTML 转义；原有试点回归独立运行。HTML 为本地静态查看，无学习者状态和交互式教学功能。浏览器验收应检查桌面及窄屏布局、中文、14项、两种状态、链接；本次未执行浏览器检查，不得标为通过。

## 第二阶段：原设计与后续实现

以下为原方向；C01/C02 最小闭环的当前数据结构、保守规则及使用方法以 `minimal-evidence-design.md` 为准。

每位学习者使用独立的本地私有目录和随机化名，目录不进 Git（现有 `**/records/` 忽略）；访问控制、备份、家长查看与彻底删除机制须实施并验证，忽略规则不是安全隔离。不得提交真实儿童数据。事件追加记录应分别包含：会话和学习机会 ID、时间、概念及题卡版本/散列、原始回答和理由、AI 临时正确性及理由评价（可 unknown）、H0—H3 和其他支持、迁移任务及表现、家长反馈、暂停/恢复/结束。保留多次独立学习机会、证据引用、待复习概念及日期；概念个人状态、内容发布状态和知识本体分开。避免收集真实姓名、学校、定位等不必要信息，允许家长删除。

调度先重新 survey 根 Wiki 和试点快照，并在每次进入或恢复概念前完整读取相关页面、核对来源和现有发布门禁；失败则停止，不用缓存补救。起点诊断只确定候选起点与难度，不授予掌握。结合不同机会的原始证据、解释质量、提示依赖及陌生情境迁移，由家长复核：证据充分才进入满足硬先修的候选；解释不清换已发布的不同情境巩固；多次困难时降难或回补先修；已学概念根据上次表现安排间隔复习。候选之间追踪六能力覆盖并兼顾薄弱领域；任何候选若无发布题卡则阻断，不能临时生成题目。暂停或疲劳不当作失败。一次正确或固定 80% 均不足以升级；现有参考计划中的次数和间隔是待验证假设，不能独立决定掌握。必要的不同情境、迁移和诊断题均须先人工审核发布；目前题卡不足，调度设计尚不能完整实施。
