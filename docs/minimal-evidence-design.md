# C01/C02 学习证据最小闭环

> 历史设计记录，以下接口和固定题卡规则已经退役，不可用于教学或晋级。当前隔离协议见 [Sigma 适配协议](../experiments/sigma-integration/ADAPTER.md)；历史文件只读保留。

## 范围和数据

本模块是现有 coach 的只读消费者，不更改教练、Wiki gate、题卡或审核。仅接受已有 C01/C02 正式训练会话结束会话的最后一次作答；诊断不计掌握。同一会话同一题只采集一次。每条追加到 `pilot-c01-c02/records/<化名>/evidence.jsonl`，跟随现有记录忽略规则；使用现有锁串行写入。证据字段分别保存会话 ID、概念、题卡 ID/版本/散列、采集时间、原始回答、由记录人提供的原始理由摘录、AI 临时正确性、解释质量、作答前最高提示级别、之前尝试次数、作答前其他支持、迁移观察（unknown/no/yes、文字、家长对陌生情境的核实）、会话已有家长反馈，以及采集时补充的家长反馈。原答由 coach 事件直接复制，不因评价而覆盖。理由摘录须原话，不是 AI 补写；若原答没有理由留空。补充字段由家长录入，仅供观察，不自动证明其真实性。

`capture` 从现有 `events.jsonl` 读取会话和最后一次尝试并检查记录中的题卡版本与当前发布门禁；从标准输入接收 JSON 补充字段，避免在命令行参数中暴露原话。`assess` 即时聚合；家长使用 `confirm-c01` 确认符合条件的候选，确认记录绑定 C01 证据摘要；`recommend` 基于即时聚合、确认与 Wiki 构图，只返回建议、不执行教学。允许家长查看及删除本地整个化名目录；本地文件权限和 Git 忽略不是加密或多用户安全隔离。不要采集姓名、学校、位置等不必要信息，不提交真实儿童数据。

历史题卡通过对应不可变归档、版本登记和当时的审核记录核验；旧版本证据仍可读取，但在单独审核其适用性之前不计入掌握判断。归档或审核损坏时停止评估，不将证据静默视作有效。

## 决策

- 完成：coach 的会话状态，只说明训练已结束（包含跳过或结束）。进度：每概念去重后的证据机会数，不等于掌握。
- 合格机会：最后一次回答 correct、理由 valid、H0/H1，之前至多一次尝试，且作答前无平行示范或完整讲解。采集记录必须来自不同会话，且题卡版本当前仍通过门禁。
- `mastered_candidate`（建议家长复核而非自动最终认定）：至少两个合格机会、不同已发布训练题卡，且其中至少一项由家长核实是陌生情境的迁移观察。不能凭一次回答、重复同题、一次完成、诊断、或固定正确率晋级。其余一律 `pending_confirmation`；如记录显示解释不清或多次困难则返回对应观察，不自动贴标签。以上是保守工程规则，非经过验证的测量标准。
- C02 的推荐需要 C01 达到候选条件并经家长单独确认；确认绑定当时的 C01 证据摘要，C01 证据变化即失效，新增 C02 证据不使新格式确认失效。旧格式确认绑定全量证据，只有全量摘要仍匹配时才有效；否则须家长重新确认，不自动推断历史确认范围。起点诊断仅供人工选择难度。C01 仍需即时通过现有 Wiki 与题卡发布门禁；若不足以推荐安全的已发布任务则返回阻断。当前每个概念仅一张已发布训练卡，不能以重复练习制造多题迁移证据；当前无法达到候选条件。
- 这只是下一步建议，重复练习建议不代表能满足新情境证据；无法迁移时提示人工等待已发布材料。现有会话仍必须经家长陪同和 coach 现场门禁，绝不自动启动。

## 验收

用合成数据检验证据字段独立、化名隔离、重复采集防重、单次与重复同题不能晋级、跨机会与迁移缺失仍待确认、合格聚合逻辑、C01 先修与发布撤销均阻断推荐；重跑 Roadmap 和 22 项 coach 测试。不在仓库保存真实儿童样本。

## 操作示例

先用原 coach 结束试点会话，从 `progress` 返回的 `session_id` 取得会话 ID。以下数据只是格式示例；实际原话和家长反馈应仅通过本地标准输入提供，不保存到仓库。

```sh
python3 scripts/learning_evidence.py capture --learner <化名> --session <会话ID>
```

向标准输入提供一个 JSON 对象并结束输入，例如 `{"reason_quote":"孩子原话中的理由", "transfer":{"status":"unknown", "observation":"", "parent_verified_novel":false}, "parent_feedback":"家长观察"}`。理由须是原答中的原话，未知可用空字符串；迁移为 `yes` 且家长确认陌生时须提供观察。然后运行 `python3 scripts/learning_evidence.py assess --learner <化名>` 和 `python3 scripts/learning_evidence.py recommend --learner <化名>`。只有 C01 达到候选、家长亲自审阅证据并决定确认时，才运行 `python3 scripts/learning_evidence.py confirm-c01 --learner <化名>`，再重新获取建议；它不是题卡发布或自动审核。
