# Sigma 动态评估与晋级设计

状态：**C01 → C02 动态候选、模拟确认、规划和使用点门禁已接入隔离合成试点**。聚合本身不授权晋级，真实儿童入口仍关闭。现行协议仍是 [ADAPTER.md](../experiments/sigma-integration/ADAPTER.md)；儿童正式入口关闭。旧 Coach、题卡和审核代码保留。

## 决策与待定事项

**已决定**：保留同一个 Sigma Agent，Wiki 驱动教学、动态追问和四维掌握评价；教学题和评估题均由 Sigma 动态生成，不再把预先审核的固定题卡作为新机制的晋级前提。优先复用现有会话、证据、规划存储和校验；不增加 Tutor、Planner 或独立 AI 评估 Agent。旧数据均为合成测试时不开发迁移兼容层。试点只使用隔离合成数据。

**已决定**：独立学习会话跨固定 UTC+8 的不同自然日，且用于满足跨会话条件的两次有效评估间隔至少 12 小时；试点每次概念晋级前须家长确认，无须逐题确认。概念级内容授权以经人工审核的 Wiki 概念、教学目标、知识边界和来源为基础，绑定内容版本和摘要，并支持撤销。

**待确定**：可信家长操作入口的具体实现，以及概念授权的责任人、版本记录和撤销操作流程。当前只允许合成模拟，Agent 声明不能认证身份。

**已实现（仅隔离合成数据）**：C01 概念授权的检查、内容变化失效及撤销检查；动态教学与评估事件的事前声明、原答、支持、四维评价、更正和失效记录，以及授权失效时的原答中断保存。记录层现由存储程序生成 UTC 时间与会话边界，保存重复、陌生迁移、关键混淆和支持完整性的语义观察及依据；这些能力仅在合成数据中验证。真实可信人工审核授权仍未实现。

**已实现（仅隔离合成数据）**：`python3 scripts/learning_evidence.py dynamic-candidate --learner synthetic` 在锁内读取现有会话快照与实时授权，按 `C01-dynamic-candidate-v1` 只读重算各条件、证据详情和摘要；不写入候选库，也不调用正式门禁。每次调用重读全部事件，更正取最新评价，失效和中断不计有效题，授权撤销或变化阻断候选。摘要绑定规则、完整快照和实时授权检查结果。

**已实现（仅隔离合成数据）**：`assess`、`recommend`、模拟 `confirm-c01`、路线输入和 C02 实际使用点都读取同一个动态候选。C02 入口重新检查 C01 候选、明确标记的模拟确认、当前已确认路线、C02 内容授权、Wiki、先修和保留的题卡发布门禁；旧题卡确认不可重放。Coach 的实际动作在发布锁和学习者锁内检查，不依赖 wrapper 的提前判断。

**待实现、待验证**：真实身份认证、真实人工内容授权、生产级防篡改及真实使用端到端验收尚未实现；存储时间依赖本机时钟，不证明真实身份或防篡改时间；语义观察和支持完整性仍依赖 Sigma 如实判断，结构检查不能证明其正确；试点阈值未经测量验证，不构成能力测量结论。

| 复习 | 恢复时优先间隔复习，失败回到学习 | 动态复习队列已有，但不构成正式证据；另有正式证据驱动的复习 | 复用动态队列；事先声明为评估且符合全部条件的复习题可计证据 |

## 目标流程（部分记录层已实现）

1. 恢复并重新 survey；进入或恢复概念时重读根 Wiki、试点概念和相关资料，检查路线、先修和内容授权。缺失或冲突时停止受影响活动，不用常识补 Wiki 空白。
2. Sigma 动态出教学题，一次一问，依据原答追问、最小提示、反例或休息；教学题可发现困难及安排复习，不得事后改称评估题。
3. 出题前声明评估用途，记录概念、Wiki 来源及摘要、情境、考查维度和可接受答案或判断依据；自查适龄、题意、多解、来源和与既有题的实质重复。保存成功后才展示。
4. 保存原答、所有提示和支持，Sigma 对准确、解释、陌生应用、辨析分别记录成立、不成立或未考查，并引用原答及 Wiki 依据。澄清表达可追问；揭示方向的追问记为提示。生成性实践可事先设计为评估题。
5. 从已提交事件采集并校验，规则程序聚合候选，展示原题、原答、评价、未解决问题及证据摘要供复核。确认及进入下一概念前重新核对证据、Wiki、先修和授权；变化或失败即停止并重评。
6. 恢复时先处理到期复习；复习失败可使掌握状态待重新核查并暂停依赖它的晋级。会话与复习队列不是跨文件事务；中断后先读两侧核对，不声称均已成功。

## 最小晋级规则（待验证试点阈值）

同一概念须同时满足：

- 至少 3 道有效动态评估题、2 种实质不同情境、2 次独立学习会话。
- 至少 2 道无解题提示或示范、回答正确且理由成立；至少 1 道成功应用于学习者此前未见过的陌生情境。只替换名称或数字不算新情境。
- 四维均有可追溯的正向观察；未考查为 unknown，不能算成功。同一道题可覆盖多维；完成一次生成性实践，可与评估题合并。
- 无尚未解决的关键概念混淆。解决需学习者说明旧想法的问题，并在会触发该混淆的新情境中正确处理。

有效表示题目、作答及评价足以支持判断，不等于答对。有效错误计入覆盖数量，但不计入成功；出现关键混淆或表现不稳定时不得机械晋级。独立会话须有明确结束与恢复事件，立即重开或人为拆分连续作答不算独立。用于满足跨会话条件的两次有效评估须分别属于不同会话，按固定 UTC+8 换算后处于不同自然日，且两次评估时间相隔至少 12 小时；缺少可信时间或会话归属时不计入该条件。

每题未必考四维，不能将未考查当零分硬套上游逐题 3/4 和总体 80%；保留四维和实践，试点后再决定是否需要稳定的总体分数规则。证据不足为待评估，不能由自评或单次正确补足。

## 异常、纠错与停止

| 情况 | 处理 |
|---|---|
| 歧义、条件缺失、超出 Wiki 或依据不明 | 停止该题评估，保存原记录并标无效，修订后出新题；Wiki 冲突或授权不明时停止受影响活动 |
| 多解 | 接受有 Wiki 支持且推理成立的答案；无法判断则待核查，不按预设答案强判 |
| AI 评价错误或被质疑 | 追加更正及依据，不覆盖原评价；暂不计受影响证据，重算候选及确认。不能可靠判断时暂停晋级 |
| 重复 | 比较解题结构、考点和情境，而非仅比较 ID 或文本；实质重复不算独立题或陌生迁移，不确定则不计数 |
| 提示污染 | 解题方向、关键原理、示范、引导追问及前题泄露均记录为支持；该题不能计入无提示成功。不确定按有提示处理，另出未泄露的新题 |
| 证据不足、事件缺失、归属不清 | 待评估；不得猜测。孤立回答、重复 ID、多个未答题或提交冲突须停止并核对 |
| 疲劳、拒绝、挫败 | 立即停止并保存，不为凑数继续 |

结构校验不能证明语义正确、陌生性或题目质量；Sigma 必须给出依据，不确定时保守处理。安全停止规则优先于评估进度。

## 当前只读聚合边界

聚合只接受 `synthetic` 系列化名。每题先核验出题声明、原答、四维和观察的引用及授权，再独立报告有效性与准确性；有效错误可计有效题，只有 accuracy 和 explanation 均为 supported、支持完整性 confirmed 且没有关联支持时才算无提示成功。重复为 yes 或 unknown 不计独立题；完全相同原题也不计。情境需文本不同且有 Sigma 的非重复判断，程序不能证实语义差异。陌生迁移还要求有先前已作答且未失效、中断的关联题，并有无提示正确理由及陌生应用正向评价。生成性实践须为事前声明的有效题且有正确作答和理由依据。四维 unknown 不计正向证据；关键混淆 unknown 阻断候选，resolved 须有正确与解释的正向证据并关联先前混淆。即使重复题不计覆盖，其有依据的关键混淆仍阻断。

独立会话必须能沿 `session_end` / `session_resume` 追溯，使用存储生成的 UTC 作答时间按固定 UTC+8 比较跨日和至少 12 小时；缺少或冲突时保守阻断。程序核对引用存在和一致，不能验证 Sigma 的语义判断、真实时间、身份或防篡改性。结果包含题目、原答和判断依据，可能含敏感内容；目前仅用于隔离合成数据。隔离入口已接入这一候选；它不能用于真实儿童或作为真实家长确认。

## 家长确认边界

试点每次概念晋级前须家长确认，不要求逐题确认。现有摘要只能绑定候选或证据，`confirm-c01` 的文件内容和 Agent 自称“家长已确认”均不验证身份。隔离测试只能使用明确标记的模拟确认。真实使用前需可信产品入口或家长本人直接操作的受控流程提供可验证身份和明确确认，并完成反重放、证据变更失效及端到端验收；成人陪同、重新规划请求和旧确认均不自动批准新候选。路线确认不代替内容授权或先修检查。

## 隔离切换状态

旧数据均为合成测试时，选定新规则版本后在隔离试点从空证据开始采集动态评估；历史测试与验收资料保留作档案，不计入新规则。不开发题卡证据迁移、换算或兼容层，也不长期并行两套晋级规则。聚合、规划校验和实际入口门禁已切换，使旧确认不能授权新规则。Coach、题卡和审核代码保留；C02 的隔离入口依然使用已发布题卡，动态 C02 教学与评估尚未实现。儿童正式入口保持关闭。

## 验收用例与边界

1. 跨两次独立会话的三道有效题满足情境、无提示理由、迁移、四维及实践条件且无关键混淆：生成候选；确认及实时门禁通过后才能进入下一概念。
2. 仅改名的题、立即重开的会话、已示范的迁移分别不满足不同情境、独立会话和陌生迁移；教学题不能事后转为评估。UTC+8 跨日但不足 12 小时、超过 12 小时但仍在同一 UTC+8 自然日均不能满足跨会话条件；两条件同时满足才可计入。
3. 两次正确中一次受提示，或存在未解决关键混淆：不晋级，原始错误与提示保留。
4. 接受合理多解；歧义题及错误评价追加失效或更正，重算聚合；旧证据绑定确认失效。
5. 未答问题恢复原题；修订冲突、重复采集、会话与复习队列中断时停止核对，不丢原答、不重复计数。
6. Wiki 缺失、路线过期、授权撤销、先修不足或儿童要求停止时阻断受影响流程；检查各入口不能绕过。
7. Agent 自称家长确认、旧摘要重放、证据变化后使用旧确认均不能授权；模拟确认明确标记，无需逐题确认，真实身份通道单独验收。
8. 概念授权绑定经人工审核的概念、教学目标、知识边界及来源的版本和摘要；内容变化或撤销后阻断受影响流程并重新核对。概念授权通过但动态题质量不合格时，该题不计证据。

## 隔离调用与验收

在临时项目副本中先建立明确标记的 C01、C02 合成模拟授权；不预置有效授权。记录 C01 评估后调用 `learning_evidence.py assess` 或 `dynamic-candidate`，达标时以 `confirm-c01 --learner synthetic --synthetic-confirmation` 写入仅供模拟的确认。随后调用 `validate_personal_roadmap.py context`，用其三个输入摘要生成路线，经 `sigma_plan_store.py prepare` 和 `publish --confirmed-sha <摘要> --synthetic-confirmation` 模拟确认路线。`formal_gate.py check/start --learner synthetic --concept C02` 仅供预检；`coach.py start --learner synthetic --mode C02` 及后续活动动作在持锁使用点再次检查。

确认绑定概念、规则版本、动态快照摘要、C02 模拟授权及根 Wiki 摘要；修改聚合规则或摘要契约时必须递增 `DYNAMIC_RULE_VERSION`，不能依靠程序自动识别规则代码变化。路线输入再绑定确认、动态证据、C02 授权及 Wiki。完整快照摘要保守地包含普通会话修订和状态，因此普通教学事件或状态变化也可能使确认和路线过期；当前不声称只对实质变化失效。旧路线缺少模拟确认标记即过期。仅遵守同一发布锁、学习者锁及规划锁的并发读写受协调；直接修改文件、系统时钟或伪造合成文件不受保护。`tests/test_dynamic_transition.py` 在隔离合成数据中覆盖正向入口、无确认、旧确认、证据更正/失效、授权撤销、Wiki 和先修变化、直接调用及并发。
