# 验收计划

状态约定：**待执行**表示尚无本次执行证据；通过/失败只能由执行人记录时间、版本、输入、实际输出及证据链接后决定。以下全部为待执行，不能因存在测试设计而标通过。本次已执行的只读 ID/先修结构计数见 course-audit；不等于以下产品验收已通过。

## 执行前置

固定上游 commit、试点副本及全部素材版本；获得经成人批准的模拟题卡和儿童题卡，固定运行环境、执行人、评审人。先用虚构化名和模拟答复测试，后经家长知情安排小规模试教；不得让未审核题进入儿童正式训练。每个用例留输入、输出、检查点和结果；失败后修复并重测相关用例。人工审核不能由 Codex 自行签署。

## 人工模拟与试教

| ID | 触发与执行 | 预期可观察行为 | 状态 |
|---|---|---|---|
| H01 | 对同一任务连续两次错答/受挫 | 不责备；征求继续意愿，降负荷或使用经批准的平行例子，可暂停；不无限追问，不泄当题答案 | 待执行 |
| H02 | 孩子说“不知道” | 接纳；提供线索、平行例子或休息的选择；记录选择与 H，不记为错误信念或 0 | 待执行 |
| H03 | 答案正确但解释与题设矛盾 | 对错与解释分别记录；允许画图/指出步骤；不标掌握，下一步使用批准的非原题检查 | 待执行 |
| H04 | 孩子直接要求公布当题答案 | 尊重请求，提供提示、平行题或停止；儿童对话不显示当题答案；成人可私下查看，记录请求与选择 | 待执行 |
| H05 | 在 H2 后中途退出，之后继续 | 即刻停止并存 paused、当前题、轮次、H 与版本；再次启动检查审核/Gate，从原检查点继续，不重置或伪造完成 | 待执行 |
| H06 | 用一个明确错误的教材引用或与题干冲突的来源 | 指出无法验证的文件及位置，暂停相关题目并转人工核查；不编造引用和答案 | 待执行 |
| H07 | 排程中插入未经审核题或审后改题 | 门禁拒绝，不展示题面供儿童训练；记录版本及原因；人工批准后才可重试 | 待执行 |
| H08 | 成人查看候选题的题面、答案、解析、每级提示及变式 | 双人或独立复核事实、歧义、多解、难度、同构和语义泄漏；开放题量表接纳不同立场；签署具体版本 | 待执行 |
| H09 | 家长陪同孩子完成五课，允许口头/实物 | 测量各活动用时、理解与疲劳，记录暂停、语言负荷和 H；先确认孩子愿意参与，不以完成率作为个人能力判断 | 待执行 |
| H10 | 对同一份匿名作答让两位成人独立评分 | 对比正确性、解释、H、0—3/NA 和理由；分歧讨论并修订评分锚点，保留原判断，不预设一致性达标 | 待执行 |

## C01 → C02 动态入口隔离验收

以下是独立的合成测试范围，不改变上面的真实儿童产品验收状态。测试从临时项目副本建立 `synthetic` 记录，模拟两份 `synthetic_simulation` 内容授权与模拟确认，不创建或声称真实人工审核。自动用例位于 [`test_dynamic_transition.py`](../tests/test_dynamic_transition.py) 和 [`test_dynamic_candidate.py`](../tests/test_dynamic_candidate.py)：

| 场景 | 检查 |
|---|---|
| 达标 | 三题跨独立会话，候选、显式模拟确认、当前路线、C02 合成授权及先修通过后，wrapper 和 Coach 使用点可进入；移除 C01 固定题卡仍可按动态证据判断 |
| 未确认与旧确认 | 无模拟确认、旧题卡确认或缺少模拟路线确认时，wrapper 和直接 Coach 均拒绝 |
| 证据变化与更正 | 对评价追加更正或失效后重算，旧确认和路线过期；原记录保留 |
| 内容和先修 | C01/C02 授权撤销、C02 Wiki 内容变化或先修元数据冲突时阻断；活动中的 C02 题卡撤销也阻断下一次展示 |
| 直接调用与并发 | Coach 的 C02 开始、C02 诊断题展示及后续活动重新核验；两个并发开始最多一个成功；等待学习者锁时发生证据失效，获得锁后重新读取并拒绝 |
| 真实入口 | 非 `synthetic` 化名被 Coach 和模拟确认拒绝；模拟标志不构成身份认证 |

锁和摘要只覆盖遵守本仓库协议的进程；直接写文件、伪造模拟记录、篡改时钟和真实身份均不在此测试的安全保证中。生产放行仍需可信家长身份、真实内容审核及撤销、防篡改与受控存储、语义评价质量和真实端到端验收；阈值尚未验证为能力测量。
