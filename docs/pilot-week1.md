## 课次、流程和验收

下表的“验收”是会话完成条件与可观察证据，不是强制孩子达标；未完成或暂停按 NA 及原因记录。涉及空缺题时先完成上述审核，不可现场生成后立即发布。

| 节次 | 已有/拟补题及流程 | 离堂验收 |
|---|---|---|
| W01D1 | D01、D03、D05 各约 2—3 分钟，先听原答不提前纠错；剩余时间观察一件熟悉物品、简短复盘。首日无前次检索。 | 三项记录原答、理由/NA、H、投入感受，至少留下一个可见事实与猜测的起点线索；没完成记 NA。 |
| W01D2 | D02、D04、D06 各约 2—3 分钟；余下时间用 ST-C02-01 的经审核题卡做物品/卡片比较，最后复盘。 | 三项诊断有记录；比较记录相同/不同维度及提示级别。六项只构成起点线索。 |
| W01D3 | 2 分钟回顾；不同平行例示范；经审核四句话题作为主任务，可参考 ST-C01-01；让孩子区分事实和推测、说明依据、简短复盘。 | 记录能否独立重述两条事实及其依据；若不足则记录帮助与下一步，不标 mastered。 |
| W01D4 | 回顾 C01；使用经审核的 ST-C02-02 或 ST-C02-01 未暴露版本及卡片，逐维比较，再用审核过的引导提出一个可核查问题。 | 能否说明两同一异、维度一致并提出可验证问题；记录原答及 H。已经在 D2 用过的原题不得冒充新题。 |
| W01D5 | 使用经审批的全新陌生物品题测试事实、推测及验证办法，可用 ST-C01-02 作练习而非新题；口头复盘有效方法。 | 记录事实/推测/理由及可核查方法，孩子能否说出一个方法；与 W01 周目标“两个陌生场景各 3 事实+1 推测、两属性比较”分别对照，证据不足保持 in-progress。 |

D3—D5 的建议时间：回顾 2、平行示范 3、主任务 10、理由 3、复盘 2 分钟，可调整。每轮一个主要问题和最多一个必要追问；同一课不为了满足数量反复追问。

## 互动、恢复与反馈

- 开始前成人核对批准版题卡、来源、相应教学页与审核散列；进入概念前完整读对应页并记录时间与版本。诊断跨概念时读取对应的经审核诊断参考页，不触发未掌握概念的正式教学。若所需资料未通过审核或来源不一致则停止并报告成人。
- 独立作答 H0；请求帮助/不知道时提供选择：线索 H1、平行例子或休息；继续受阻且愿意时 H2；连续两次受挫用 H3 的已批准平行例题或简化任务，仍不愿继续就结束。答案对但解释错记录正确性和解释两项，不能判掌握。
- 孩子要求公布当题答案时，先承认请求并提供线索、平行例子或暂停；不在儿童对话中公布当题答案。成人可在私下查看答案；是否允许孩子事后看完整当题答案需单独设计和授权。上游原版严格禁止直接给答案，平行完整示范仅存在于本地适配方案。
- 每轮后成人保存化名、session/lesson、题及概念版本、时间、孩子原话摘要、对错、解释、H0—H3、0—3/NA、情绪和下一步。只记必要内容；按 data-schema 追加事件和保存检查点。退出记录 paused、题号/阶段、已用提示；下次核对版本/审批与 Gate 后从检查点继续，不悄悄换题或重复泄露答案。
- W01 自评及周报只描述具体观察和样本数量；使用 0—3 或 NA，不推断智商或全面提升。升级以独立迁移和跨机会证据为准。
